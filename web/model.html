// pipeline

From simulation to forecast

Simulate

1200 runs, random patients, 15 regimens, 10 cancers. 180 days each.

Observe

Only what a clinic could see: tumor size on days 0–21 of treatment, plus cancer, regimen, dose.

Learn

A gradient-boosted classifier (outcome) and quantile regressors (takeover day).

Calibrate

Conformalized quantile regression widens the ranges until they're honest.

Ship

Exported as JSON trees and run in the browser. Same answers as Python to 2×10⁻⁸.
